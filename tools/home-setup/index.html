CLEAN HOME · OPTIONAL SETUP

Your Home button.
Your home screen.

Make Clean Home appear when you press Home and switch your TV on. No root. No running PC needed afterwards.

1. Get ready

Install and open Clean Home on the TV first. Run this tool on the computer listed in the TV’s Developer Mode. Close Apps2Samsung while this tool connects.

This first setup supports QA55Q60BAWXXY, software T-NKLBUABC-1720.7. Other TVs can still use Clean Home from Apps.

2. Make it Home

Your original Home and startup preferences are saved on this computer before a change is made. Keep that recovery folder. This also turns off “Autorun Last App”, so switching on returns to Clean Home.

Samsung Home is still available using the Samsung Home button inside Clean Home. Your apps, accounts, picture and sound settings stay as they are.

Status

Enter your TV’s address, then choose Check TV.

Change your mind?

Use Undo on this same computer. It restores the saved Home and startup preferences. Always Undo before uninstalling Clean Home.
