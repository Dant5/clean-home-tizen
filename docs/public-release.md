# Public source boundary

This preview uses a clean source snapshot of the reviewed Q60B adaptation. It excludes private development history, personal signed widgets, installation profiles, certificates, addresses, DUIDs, recovery state and diagnostic recordings. It preserves original licences, asset credits and pinned upstream references.

See [the release process](RELEASING.md) for the build, checksums, compatibility disclosure and publication review. Public artifact creation never accepts a signing certificate or an inventory-specific favourite profile. A package download is not a backup of another app’s private settings.
